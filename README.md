# Exercícios de Estrutura de Dados – Árvores

## Descrição

Este repositório contém exercícios desenvolvidos na disciplina de Estrutura de Dados com foco em árvores e árvores binárias de busca (ABB). O objetivo é compreender os conceitos fundamentais de estruturas hierárquicas, suas operações e algoritmos de percurso.

## Conteúdos Abordados

### Árvores

* Conceitos básicos de árvores.
* Estrutura hierárquica composta por nós e arestas.
* Relação entre raiz, nós internos e folhas.

### Altura da Árvore

* Cálculo da altura de uma árvore.
* Determinação do maior caminho entre a raiz e uma folha.

### Profundidade de um Nó

* Identificação da profundidade de um nó em relação à raiz.
* Análise da posição dos elementos dentro da estrutura.

### Busca em Árvore Binária de Busca (ABB)

* Implementação do algoritmo de busca.
* Localização eficiente de elementos utilizando as propriedades da ABB.
* Comparação de valores para navegação entre subárvores esquerda e direita.

### Percurso em Pré-Ordem

* Visita dos nós seguindo a ordem:

  1. Raiz
  2. Subárvore esquerda
  3. Subárvore direita
* Aplicação do percurso para exibição e processamento dos elementos da árvore.

## Objetivo

Praticar os conceitos de árvores e algoritmos de manipulação, desenvolvendo soluções para problemas envolvendo busca, percursos e análise estrutural de árvores binárias.
